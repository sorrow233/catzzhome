# Catzz 2.7 Beta 验收清单

## 产品目标

2.7 的目标是让 Catzz 从“视觉展示页”转向可以每天使用的新标签页：打开后立即获得时间、搜索和快捷入口，需要时再展开任务、专注、笔记和日历，不破坏原有雨夜氛围。

## 核心验收

1. 首次打开完成引导，选择搜索引擎；拒绝定位时页面仍可正常使用。
2. 使用 `Cmd/Ctrl + K` 输入网址、普通关键词、`2*(8+4)`、`@gh catzzhome` 和 `/focus 1`。
3. 新建书签分组，添加、编辑、拖动、删除书签，再刷新页面确认数据保留。
4. 添加三个今日任务，确认第四个不会进入；完成或删除一个后可以继续添加。
5. 启动一分钟专注，切换环境音、暂停和恢复，等待结束后确认计次增加。
6. 新建和删除笔记；导入 ICS 文件并确认未来七天事件按时间排序显示。
7. 上传小于 12 MB 的 JPG/PNG/WebP 壁纸，刷新确认保留；删除后恢复内置壁纸。
8. 导出 JSON，清空部分数据后重新导入，确认书签、任务、笔记和偏好恢复；自定义壁纸文件不包含在备份中。
9. 登录同步，在另一浏览器登录同一账号确认结构化数据同步；自定义壁纸不应上传。
10. 将页面安装为 PWA；也可在 Chromium 扩展页加载构建生成的 `extension-dist/`。

## 回归重点

- 旧版 2.2 本地书签应自动进入 Favorites 分组。
- 无网络时已访问过的首页可打开，搜索、天气和同步应优雅降级。
- 桌面端、窄屏与“减少动态效果”模式下不得遮挡搜索、书签和设置操作。
